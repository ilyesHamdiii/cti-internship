# Rapport académique LaTeX

Ce dossier contient le rapport de stage académique en français.

Fichier principal à compiler dans Overleaf :

```text
Main.tex
```

Le dossier `template/` contient le modèle Overleaf original extrait depuis l'archive fournie. Le rapport final se trouve à la racine de `docs/academic report` et réutilise la structure LaTeX de type `report` avec chapitres, bibliographie et annexes.

Le contenu technique est basé sur `docs/COMPLETE_TECHNICAL_ENGINEERING_REPORT.md` et présente le projet comme un prototype de stage, pas comme un produit commercial prêt pour la production.
